# PC Performance Monitor

A Python-based desktop application that monitors PC performance in real time.

## Features

- CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring for C: and D:
- Download speed monitoring
- Upload speed monitoring
- Top 5 processes by RAM usage
- Live GUI updates

## Technologies Used

- Python
- Tkinter
- psutil

## How to Run

1. Clone the repository.
2. Install the required library:

```bash
pip install psutil
